## Safety Considerations

- **Drug Interactions**: The compiled data record 100 interactions. The 20 reviewed here include the following main ones:
  - **Major**:
    - Corticosteroids: hydrocortisone, prednisone, prednisolone, dexamethasone, betamethasone, budesonide, triamcinolone (including the ophthalmic form).
    - Deferiprone.
    - Radiopharmaceuticals: iobenguane (I-131), ibritumomab tiuxetan, tositumomab (I-131).
  - **Moderate**: metronidazole, tinidazole, naltrexone, rosuvastatin, simvastatin.
  - **Minor**: zinc salts (sulfate, acetate, gluconate).

For warnings and contraindications, please refer to the package insert.
