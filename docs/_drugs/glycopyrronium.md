## Why is This Prediction Reasonable?

Currently, detailed mechanism of action data is not available. Based on known information, glycopyrronium is a muscarinic (anticholinergic) antagonist, and it appears in several inhaled single-agent and combination products in Singapore.

Antimuscarinic antispasmodics are a recognised drug class for the visceral hypermotility and pain seen in IBS. This link is a **class-level rationale only**. No glycopyrronium-specific data for IBS were provided. Its relationship to the respiratory products is therefore indirect: the shared pharmacology is muscarinic blockade, not a shared disease process.

The model's high score should be read cautiously. The only retrieved paper studied tricyclic antidepressants on colonic afferent nerves in rats, so it does not support glycopyrronium in IBS.

## Conclusion and Next Steps

**Decision: Hold**

**Rationale:**
The evidence is model prediction only (L5). There are no trials, and the single publication is not drug-relevant. The only registered Singapore products are inhaled, so route compatibility with an oral IBS use is unresolved.

**To proceed, the following is needed:**
- Package insert warnings and contraindications from HSA, which currently block safety screening
- Mechanism of action data from DrugBank
- Glycopyrronium-specific clinical or observational evidence in IBS
- A route and formulation compatibility assessment, since only inhaled products are listed
- Consideration of the "autonomic nervous system disease" candidate (rank 8, L4), which has more supporting literature. It is a broad term, so a specific indication such as hyperhidrosis or drooling should be defined first.
