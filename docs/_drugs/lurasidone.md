## Why is This Prediction Reasonable?

Detailed mechanism of action data is not available in the data compiled for this report. Based on known pharmacology, lurasidone is an atypical antipsychotic that blocks dopamine D2 and serotonin 5-HT2A receptors and also acts on 5-HT7 and 5-HT1A receptors. Atypical antipsychotics with this profile are commonly used to treat manic symptoms, so an antimanic effect is plausible.

The predicted indication overlaps heavily with the original use. Lurasidone is already used for bipolar disorder, so this is an extension within the same disease family, not a true repurposing signal. The existing literature is mostly about bipolar depression, not acute mania, so the evidence for mania is indirect.

## Conclusion and Next Steps

**Decision: Hold**

**Rationale:**
The only trial directly addressing mania was withdrawn with no participants, and the literature is mainly general bipolar reviews and guidelines, or lurasidone studies on bipolar depression. Because lurasidone's current use already covers bipolar disorder, this prediction is an extension within the same disease family and offers little new repurposing value. The prediction therefore remains a research question (L4).

**To proceed, the following is needed:**
- Randomised controlled trial data for lurasidone in acute manic or mixed episodes
- Package insert warnings and contraindications from HSA
- Detailed mechanism of action data (MOA)
- Review of the Singapore licensed indication wording, since the licence records contain no indication text
- A safety plan covering metabolic risk, extrapyramidal symptoms and the major drug interactions
