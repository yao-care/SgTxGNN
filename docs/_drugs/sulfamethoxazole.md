## Why is This Prediction Reasonable?

Currently, detailed mechanism of action data is not available. Based on known drug-class information, sulfamethoxazole inhibits bacterial dihydropteroate synthase, which blocks bacterial folate synthesis. That mechanism could plausibly act against the bacteria that cause acute conjunctivitis.

Acute bacterial conjunctivitis is a common, highly contagious infection, usually treated empirically with broad-spectrum topical antibiotics. An antibacterial with a different mechanism is therefore a conceivable fit. This link rests on class knowledge only.

Nothing shows that systemic or topical sulfamethoxazole works for this condition. The one publication describes which bacteria cause childhood conjunctivitis and how they respond to antibiotics. It is indirect evidence. None of the dosage forms registered in Singapore (tablet, suspension, injection) is an ophthalmic preparation.

## Safety Considerations

Please refer to the package insert for safety information.

Related signal from the evidence pack: a 1985 case report (PMID 3157322) describes erythema multiforme after topical sulfacetamide, a different sulfonamide, used for conjunctivitis. This is not direct evidence about sulfamethoxazole, but it is a hypersensitivity consideration for any ocular sulfonamide use.
