# Trospium: From Overactive Bladder to Irritable Bowel Syndrome

## One-Sentence Summary

Trospium is a peripherally acting antimuscarinic (quaternary ammonium) drug, marketed for overactive bladder. The TxGNN model predicts it may be effective for **irritable bowel syndrome**. Evidence is very thin: **no clinical trials** and only **1 loosely related publication**, which does not study irritable bowel syndrome (IBS).

## Why is This Prediction Reasonable?

Detailed mechanism-of-action data is not available in the data compiled for this report. Based on known information, trospium is an antimuscarinic with a quaternary ammonium structure. It acts on peripheral muscarinic receptors and reduces smooth muscle contraction in the bladder, and its efficacy in overactive bladder is established.

Antimuscarinic and antispasmodic agents are used for abdominal cramping in IBS. Reduced smooth muscle contractility in the gut is therefore a plausible mechanism for benefit.

However, the only linked publication (PMID 33890538) is about antimuscarinic use in older adults with dementia and overactive bladder, not IBS. No IBS-specific study of trospium was found. The high TxGNN score is a model prediction only and has not been confirmed by clinical data.

## Safety Considerations

- **Drug Interactions**: The interaction screen returned 100 records. The 20 listed in the data compiled for this report are mostly Moderate, with a few Minor. Examples:
  - **Moderate**: other anticholinergic or antimuscarinic agents (aclidinium, chlorpheniramine, acrivastine, phenyltoloxamine, amitriptyline), opioids and central nervous system depressants (fentanyl, alfentanil, codeine, dihydrocodeine, tramadol, ethanol), botulinum toxin type A, ranitidine, metformin, amantadine, acebutolol, acetylcholine and acyclovir.
  - **Minor**: acetaminophen and hydrochlorothiazide.
- **Class-related caution (from the rationale, not label text)**: Antimuscarinics can raise intraocular pressure, and are generally cautioned in angle-closure glaucoma.

Please refer to the package insert for key warnings and contraindications, because these were not available in the data compiled for this report.

## Conclusion and Next Steps

**Decision: Hold**

**Rationale:**
The prediction is mechanistically plausible, because antimuscarinics are already used for gut cramping. But it rests on a model score alone (L5). There are no IBS trials, and the only linked publication is unrelated to IBS. The Singapore package insert safety data is also missing, which blocks safety screening.

**To proceed, the following is needed:**
- Retrieve the Singapore package insert (warnings, contraindications and approved indication) from the HSA website
- Obtain detailed mechanism-of-action data (for example, from DrugBank)
- Systematically search for IBS-specific studies of trospium or comparable quaternary antimuscarinics
- Assess the benefit-risk in IBS, in particular anticholinergic effects such as constipation, which may worsen constipation-predominant IBS
- Consider a small proof-of-concept trial if the literature review supports it
