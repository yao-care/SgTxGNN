## Safety Considerations

- **Drug Interactions**: The interaction screen returned 100 interacting drugs, mostly of Moderate severity and a few Minor. The 20 listed in the data compiled include:
  - Sympathomimetics and bronchodilators: phenylephrine, pseudoephedrine, epinephrine, formoterol, salbutamol
  - Corticosteroids: hydrocortisone (Moderate), and topical hydrocortisone and alclometasone (Minor)
  - Diuretics: furosemide, hydrochlorothiazide, acetazolamide
  - Hormonal agents: ethinylestradiol, estradiol, norethisterone
  - Others: ethanol, fosamprenavir, fosphenytoin, gemifloxacin, alpelisib, aripiprazole

  Many of these may affect blood glucose control, so monitoring is warranted if co-administered.

For key warnings and contraindications, please refer to the package insert.
