## Safety Considerations

- **Contraindications (knowledge graph, not label text):** The knowledge graph lists dermatitis as a contraindicated disease for this drug. This should be checked against the package insert.
- **Drug Interactions:** 79 potential interactions were identified. The 20 shown in the data compiled for this report include pantoprazole, metformin, omeprazole, triamcinolone, prednisone, warfarin, simvastatin and dexamethasone. None has a severity grade, so their clinical significance is unknown. Systemic absorption from topical use is generally low, so the practical relevance is probably limited.
- **Site-specific concerns:** Selenium sulfide is an irritant. Use on vulvar mucosa, or in neonates where percutaneous absorption of selenium is a concern, would need careful assessment.

Please refer to the package insert for the remaining safety information, such as warnings and contraindications.
