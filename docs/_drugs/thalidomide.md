## Safety Considerations

- **Contraindication-related disease associations (from the knowledge graph, not label text):** multiple system atrophy, postural orthostatic tachycardia syndrome, orthostatic hypotension, epilepsy, neutropenia, agranulocytosis, peripheral nervous system disease, peripheral neuropathy, pulmonary embolism.
- **Teratogenicity:** thalidomide is a well-known cause of severe birth defects. This is a major barrier for any new indication, especially for the developmental syndromes in the prediction list.
- **Drug interactions:** 100 interactions were found in the DDI screening. The major-level ones listed here are all corticosteroids: hydrocortisone, triamcinolone, dexamethasone, betamethasone and prednisone. Moderate-level interactions include H2 blockers (famotidine, ranitidine, cimetidine, nizatidine), antiemetics (ondansetron, dolasetron, palonosetron, metoclopramide), morphine, metronidazole, clarithromycin, levofloxacin, dronabinol, nabilone and picosulfuric acid.

The package insert warnings and contraindications for the Singapore product were not available, so please refer to the package insert for the full safety information.
