# Cyclizine: From Antiemetic Use to Allergic Urticaria

## One-Sentence Summary

Cyclizine is a first-generation H1 antihistamine, generally used as an antiemetic for nausea, vomiting and motion sickness. The TxGNN model predicts it may be effective for **allergic urticaria**. Currently there are **0 clinical trials** and **1 publication**, and that publication is only indirectly related, so the prediction rests almost entirely on the model score and the antihistamine class effect.

## Why is This Prediction Reasonable?

Currently, detailed mechanism of action data for cyclizine is not available. Based on known information, cyclizine is a first-generation H1 antihistamine. H1 receptor blockade is the standard mechanism for treating urticaria, so the link is plausible as a class effect. However, this has not been confirmed for cyclizine itself.

The original use (antiemetic) and the predicted use (urticaria) both involve H1 receptor blockade. Cyclizine also has sedating and anticholinergic effects. Second-generation antihistamines are the established option for urticaria, so cyclizine is less attractive than they are.

Several other predictions follow the same H1 class-effect logic, including cold urticaria and rhinitis, but none has cyclizine-specific evidence. The headache prediction has some literature. It appears to come from ergotamine combinations that may contain cyclizine as an antiemetic, which suggests migraine-associated nausea rather than headache efficacy.
