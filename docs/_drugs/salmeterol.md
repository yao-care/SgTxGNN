# Salmeterol: From Asthma and Emphysema to Bronchitis

## One-Sentence Summary

Salmeterol is a long-acting beta2-adrenoceptor agonist, originally used for pulmonary emphysema and asthma (intrinsic and allergic).
The TxGNN model predicts it may be effective for **bronchitis** (mainly chronic bronchitis within COPD), with **9 clinical trials** and **20 publications** currently supporting this direction.
Most of this evidence is in COPD populations, so the new indication is a close extension of the existing ones rather than a distant repurposing.

## Why is This Prediction Reasonable?

Salmeterol is a long-acting beta2-adrenoceptor agonist. It relaxes airway smooth muscle and produces sustained bronchodilation. Detailed mechanism of action data are not available in the data compiled for this report, so this description relies on its known drug class.

Chronic bronchitis is a major COPD phenotype, and emphysema (an existing indication) is the other. The same airflow obstruction therefore underlies both. Salmeterol may also improve mucociliary and cough clearance. A small placebo-controlled study in 14 patients with mild-to-moderate chronic bronchitis (PMID 15970448) examined exactly this effect.

Several Phase 3 COPD trials include a salmeterol arm, so the prediction rests on direct clinical evidence and is not only a model output.

## Safety Considerations

- **Contraindications suggested by the knowledge graph (not label text):** hypertension, long QT syndrome (including familial), epilepsy, hyperglycaemia, pituitary hormone deficiencies, herpes simplex keratitis, thymus gland disease, and osteoporosis. These should be verified against the approved package insert.
- **Drug interactions:** 100 interactions were identified. Among those retrieved, the notable ones are:
  - **Major:** clarithromycin.
  - **Moderate:** epinephrine, famotidine, acarbose, isometheptene, dolasetron, diethylpropion, and several antidiabetic agents (albiglutide, alogliptin, canagliflozin, chlorpropamide, dapagliflozin, dulaglutide, empagliflozin).
  - **Minor:** corticosteroids (hydrocortisone, dexamethasone, budesonide, beclomethasone, betamethasone, triamcinolone).
- **Safety literature:** Cochrane reviews (PMIDs 30521673, 23543548) report serious adverse event concerns with regular long-acting beta2-agonists in asthma. Salmeterol should not be used as monotherapy in asthma and should be combined with an inhaled corticosteroid.

Please refer to the package insert for the full warnings.

## Conclusion and Next Steps

**Decision: Proceed with Guardrails**

**Rationale:**
Multiple completed Phase 3 trials in COPD and chronic bronchitis include salmeterol, and direct data show an effect on mucociliary clearance. Bronchitis is a close extension of the existing emphysema and asthma indications, so the evidence is strong. The cardiovascular and metabolic contraindication signals and the monotherapy caution in asthma require safeguards.

**To proceed, the following is needed:**
- Singapore package insert warnings, contraindications and approved indication text, which are missing from the data compiled for this report
- Detailed mechanism of action data
- Confirmation of which Singapore products carry a COPD or chronic bronchitis indication (the licence records show salmeterol only in combination with fluticasone)
- A clear definition of the target population (chronic bronchitis within COPD) and confirmation of how many of the listed trials directly test salmeterol
- A safety monitoring plan for patients with cardiovascular disease, QT prolongation, diabetes or epilepsy, and for those taking strong CYP3A4 inhibitors such as clarithromycin
